# React Currency Converter

A React + Vite practice project focused on a currency-converter interface and reusable React code.

## Tech stack

- React
- Vite
- JavaScript
- Tailwind CSS / project CSS
- ESLint

## Run locally

Requires a current Node.js LTS release.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run lint
```

## Project structure

- `src/App.jsx` — main React application
- `src/components/` — reusable UI components
- `src/hooks/` — custom hooks
- `src/App.css` and `src/index.css` — styling

## Status

This is a frontend learning project, not a financial service. Verify whether conversion rates are live or static in the implementation before relying on any displayed value. It is included as secondary evidence of frontend experience; my primary portfolio focus is Data Engineering.
